# Ретроспектива правок и архитектурный журнал: RuVK Hub

В данном документе зафиксирована полная история развития проекта, хронология версий и разбор ключевых технических вызовов, с которыми сталкивалась разработка.

---

## 1. Хронология релизов

### v1.0.0 (Начальный MVP)
- Базовый каркас Android TV приложения на Kotlin и AndroidX Leanback.
- Интеграция The Movie Database (TMDB) API: получение популярных фильмов, трендов и детальной информации.
- Первичные скраперы для поиска видеопотоков на **VK Video** и **Rutube**.
- Встроенный видеоплеер на базе **AndroidX Media3 / ExoPlayer** с поддержкой HLS (`.m3u8`) и MP4.
- Локальное сохранение Избранного и Истории через Room SQLite.

### v1.0.1
- Доработка селекторов качества видео в парсерах Rutube и VK Video.
- Фильтрация недоступных, заблокированных или удаленных правообладателями видеороликов.
- Устранение вылетов при отсутствии стабильного интернет-соединения.

### v1.0.2
- Доработка навигации пультом ТВ (D-pad): устранение «застревания» курсора при переходе от карточек к системным элементам.
- Внедрение визуальных селекторов фокуса с белой рамкой.
- Поддержка воспроизведения русскоязычных трейлеров.

### v1.0.3
- Исправление парсинга метаданных в Истории просмотров.
- Добавлено автоматическое определение максимального качества (1080p / 720p) для прямых потоков Rutube.
- Оптимизация сетевых таймаутов в `OkHttpClient`.

### v1.0.4
- **Каталожный полнотекстовый поиск:** поиск по всей базе фильмов и сериалов TMDB через строку ввода.
- **Отслеживание прогресса просмотра:** сохранение точного таймкода в Room DB с визуальным отображением красной полосы прогресса на карточках.
- **Возобновление просмотра (Resume):** кнопка «Продолжить» с указанием сохраненного времени.
- Унификация скруглений постеров карточек до 10dp.

### v1.0.5
- Исправление исчезновения постеров в результатах поиска.
- **3-шаговая навигация клавишей Back:** возврат из источников к кнопкам, из кнопок к каталогу, из каталога к выходу.
- Возобновление последнего сохраненного потока в один клик без повторного поиска по источникам.

### v1.0.6
- **Фильтрация экранок (Anti-CAM):** в каталог включен жесткий фильтр только вышедших в цифре релизов (`with_release_type=4|5`), в парсерах источников добавлен черный список стоп-слов (TS, CAM, HDCAM, экранка, чистый звук).

- **Бесконечная лента:** пагинация страниц TMDB при приближении к концу списка карточек (за 5 карточек до конца).
- **Боковое быстрое меню (9 пунктов):** выдвижная компактная плашка (Поиск, В тренде, Новинки, В эфире, Фильмы, Сериалы, Избранное, История, Настройки).
- **Экран Настроек:** переключение между встроенным ExoPlayer и внешними плеерами (VLC, Vimu, Just Player), ввод персонального TMDB API ключа.

### v1.0.7

- **Динамическое смещение блоков:** блок актеров изначально расположен под кнопками, а по нажатию «Смотреть» плавно съезжает под открывшуюся панель источников.
- **Исправление артефактов на пустых экранах:** устранены зависшие бейджи (`18+`, хронометраж) и старые постеры при переходе в пустое «Избранное» или «Историю».

### v1.0.8

- **Квадратная системная иконка (1:1):** разделение ресурсов `app_banner` для лончера Leanback и `app_icon` для системного списка приложений.
- **Исправление подписей APK:** одновременное включение схем подписи **v1 (JAR) + v2 + v3** и снижение `minSdk = 21`, что устранило ошибку `INSTALL_PARSE_FAILED_NO_CERTIFICATES` на телевизорах (включая Philips UHD Android TV).

### v1.0.9
- **Шапка бокового меню:** убрана старая иконка, добавлен аккуратный заголовок **RuVK Hub** шрифтом 20sp bold с выравниванием влево вровень с пунктами меню (20dp от края) и стильной подсветкой (RuVK синий, Hub красный).

- **Фильмография актера по клику:** по нажатию на карточку актера снизу раскрывается горизонтальная полка его фильмов из TMDB в 1 ряд с сортировкой **от новых к старым**. При клике открывается карточка фильма; клавиша Back возвращает фокус на выбранного актера.

### v1.1.0 (Поддержка сериалов, сезонов и серий)
- **Иерархия сезонов и серий:** интеграция эндпоинта `tv/{tv_id}/season/{season_number}` из TMDB. В карточке сериала отображаются две горизонтальные полки: выбор сезона (стильные чипы-пилюли) и выбор серии (карточки 16:9 с превью кадра, бейджем номера серии, хронометражем и названием).
- **Точечный поиск эпизодов:** разработан алгоритм `findEpisodeSources` в `SearchCoordinator` с шаблонами запросов (`"$title $season сезон $episode серия"`, `"$title s${season}e${episode}"`, `"$title $episode серия"`), фильтрацией компиляций («все серии»), строгим regex-контролем соответствия номера серии и хронометража эпизода.
- **Индивидуальный прогресс серии:** сохранение `season` и `episode` в `HistoryEntity` Room DB. Кнопка «Смотреть» на карточке сериала отображает сохраненную серию и таймкод: `▶ (S1E2 12:34)` и возобновляет просмотр именно этой серии.
- **Интеграция с плеером:** во встроенном ExoPlayer отображается номер сезона и серии: `Название (Сезон S, Серия E - 1080p)`.
- **D-pad навигация:** продуманный вертикальный переход фокуса: *Кнопки действий <-> Сезоны <-> Серии <-> Источники <-> Актеры <-> Фильмография*, и пошаговый возврат по кнопке Back.

## 2. Разбор ключевых инженерных решений и багов

### 2.1. Обход блокировок и DNS-проблем TMDB в РФ (`TmdbDns`)
- **Проблема:** Домен `api.themoviedb.org` блокируется или некорректно резолвится многими интернет-провайдерами в РФ через стандартный системный DNS.
- **Решение:** Написан собственный резолвер `TmdbDns : Dns` для OkHttp. Резолвер сначала опрашивает системный DNS, а при сбое или для хостов `themoviedb.org` отправляет прямой легковесный UDP-пакет (порт 53) к независимому DNS Quad9 (`9.9.9.9`), парсит бинарный DNS-ответ формата RFC 1035 и возвращает корректные IPv4-адреса серверов TMDB.

### 2.2. Аппаратное скругление постеров карточек (Coil Bitmap Bleed)
- **Проблема:** Растровые битмапы постеров, загружаемые библиотекой Coil, перекрывали скругленные углы контейнера `FrameLayout` острыми краями, а атрибут `android:clipToOutline="true"` на некоторых версиях AOSP игнорировался графическим конвейером.
- **Решение:** Внедрен трехуровневый подход:
  1. Трансформация самого битмапа на уровне декодера Coil: `transformations(RoundedCornersTransformation(10dp))`.
  2. Программный `ViewOutlineProvider` с `outline.setRoundRect(..., 10dp)` и принудительным `clipToOutline = true` на контейнерах.
  3. Перенос рамок карточки и обводки фокуса в слой `android:foreground`, чтобы обводка всегда гарантированно рисовалась поверх любых дочерних картинок со скруглением.

### 2.3. Зависшие бейджи и артефакты на пустых экранах (Race Condition)
- **Проблема:** При переходе из ленты фильмов в пустое «Избранное» на экране оставались висеть бейджи возраста (`18+`) и хронометража (`30 мин`) от предыдущего фильма, а также старые постеры.
- **Причина:** Предыдущая фоновая корутина `detailsFetchJob` не отменялась при смене категории и по завершении сетевого запроса выставляла бейджи для уже неактуального элемента.
- **Решение:** В начале метода `loadCategory()` добавлены: немедленная отмена джоба `detailsFetchJob?.cancel()`, обнуление `currentMediaItem = null`, полный сброс видимости всех бейджей в `clearHeroSpotlight()` и очистка адаптера `posterAdapter.submitList(emptyList())`. При пустом результате фокус D-pad удерживается в боковом меню (`focusSideMenu()`).

### 2.4. Ошибка `INSTALL_PARSE_FAILED_NO_CERTIFICATES` на Android TV
- **Проблема:** При попытке установки релиза на телевизор Philips UHD Android TV (и ряд других устройств) через ADB AppControl установка прерывалась с ошибкой `INSTALL_PARSE_FAILED_NO_CERTIFICATES: Failed collecting certificates`.
- **Причина:** В Android Gradle Plugin 8+ при `minSdk = 28` сборщик по умолчанию отключает схему подписи **v1 (JAR signing)** в пользу v2. Однако системный парсер пакетов `PackageParser` на многих прошивках Android TV (особенно вендорских сборках Philips/TP Vision) при установке через ADB требует обязательного наличия JAR-манифеста в каталоге `META-INF/`.
- **Решение:** В `app/build.gradle.kts` для конфига `debug` (которым подписывается и релиз) явно включены все схемы:
  ```kotlin
  signingConfigs {
      getByName("debug") {
          enableV1Signing = true
          enableV2Signing = true
          enableV3Signing = true
      }
  }
  ```
  А `minSdk` снижен до `21` (Android 5.0+), что полностью восстановило генерацию v1-подписей и сняло любые ограничения совместимости.

### 2.5. Навигация D-pad в сложных многослойных экранах (`DetailsActivity`)
- **Проблема:** При динамическом появлении новых полок (Источники, Актеры, Фильмография) стандартный алгоритм поиска ближайшего фокуса Android (`FocusFinder`) мог прыгать в неожиданные места или терять фокус.
- **Решение:** Внедрен централизованный метод `updateFocusNavigation()`, который динамически пересчитывает связи `nextFocusDownId` и `nextFocusUpId` в зависимости от того, какие полки сейчас открыты. Метод `onBackPressed()` перехватывает нажатия и поднимает пользователя строго по ступеням: *Фильмография -> Актеры -> Кнопки действий -> Выход из карточки*.

### 2.6. Устойчивость механизма автообновления при переименовании APK
- **Проблема:** Переименование файла релиза из `Ru-VK-Tube-*.apk` в `RuVK-Hub-*.apk` потенциально могло сломать парсер обновлений в старых установленных версиях.
- **Решение:** Проверена реализация в `UpdateManager.kt`: поиск ассета в GitHub API использует условие `asset.name.endsWith(".apk", ignoreCase = true)` без привязки к имени пакета. Дополнительно синхронизирован файл `docs/update.json`, обеспечивающий прямую отдачу данных через GitHub Pages.
