# RuVK Hub

Автономный каталог и плеер фильмов и сериалов для Android TV (версии 9.0+ / API 21+).

## Назначение
- **Единый агрегатор контента:** интеграция с каталогом TMDB (популярное, тренды, цифровые новинки, сериалы в эфире).
- **Прямые российские источники:** поиск и прямое воспроизведение видеопотоков (HLS/MP4) и трейлеров из сетей **VK Video** и **Rutube** без прокси-серверов.
- **Воспроизведение:** встроенный аппаратный плеер (AndroidX Media3 / ExoPlayer) с управлением пультом ДУ либо запуск внешних плееров (VLC, Vimu, Just Player).
- **10-foot UI / NUM Design:** бесконечные полки в 1 ряд, двухцветное меню, полка «В главных ролях», фильмография актеров, аппаратные скругления 10dp и селекторы фокуса.
- **Полная автономность:** без серверов, регистраций и авторизаций. Локальное хранение истории с таймкодами прогресса и избранного (Room SQLite).

## Сборка и запуск
Требования: JDK 17, Android SDK (API 34).

```powershell
$env:JAVA_HOME = "D:\Projects\AndroidSDK\jdk-17"
$env:ANDROID_HOME = "D:\Projects\AndroidSDK"

# Сборка Debug APK:
.\gradlew.bat assembleDebug

# Сборка подписанного Release APK (v1 + v2 + v3 подписи):
.\gradlew.bat assembleRelease

# Запуск локального эмулятора Android TV (ATV_9 / ATV_11) и автоустановка:
.\run_emulator.ps1

# Ручная установка на подключенный телевизор / приставку через ADB:
adb install -r app\build\outputs\apk\release\RuVK-Hub-1.0.9.apk
```
