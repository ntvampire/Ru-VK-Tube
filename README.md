## 📺 Назначение и функциональные модули

**RuVK Hub** — автономный клиент и плеер для Android TV с оптимизированным 10-foot интерфейсом:

- **Интеграция с Android TV Launcher:** автоматическая публикация каналов приложения на домашнем экране («В тренде», «Избранное», «История просмотров») и системной строки «Play Next» («Канал воспроизведения») с отображением полосы прогресса досмотра, расширенных метаданных (возрастной рейтинг, оценка, год, хронометраж) и моментальным запуском по клику.
- **Аппаратное воспроизведение:** встроенный оптимизированный видеоплеер на базе AndroidX Media3 (ExoPlayer) с аппаратным декодированием HLS (`.m3u8`) и прямых MP4 потоков, управлением с пульта ДУ и защитным затемнением экрана при длительной паузе.
- **Цифровая обработка звука (DSP):** аппаратная динамическая компрессия речи (`LoudnessEnhancer` +3 dB) на уровне сессии PCM Stereo для комфортного баланса диалогов и спецэффектов без искажений.
- **Leanback 10-foot UI:** дизайн в стиле NUM — однорядные горизонтальные ленты с аппаратным скруглением постеров 10dp, плавным масштабированием фокуса, выдвижным компактным боковым меню и полкой серий/сезонов.
- **Автономность и локальное хранилище:** локальная база данных Room SQLite на устройстве для хранения истории, позиций воспроизведения по каждому эпизоду и избранного без внешних серверов и регистрации.
- **Автообновление:** проверка актуальных релизов при старте приложения с возможностью установки через системный менеджер пакетов Android.
