Автономный каталог и плеер фильмов и сериалов для Android TV (версии 9.0+ / API 21+).

## Назначение
- **Каналы главного экрана Android TV:** интеграция с Android TV Launcher (Android 8.0+ / Leanback Channels) — автоматическая публикация каналов «В тренде», «Избранное», «История просмотров», а также системной строки «Play Next» (Канал воспроизведения) с отображением полосы прогресса воспроизведения, расширенными метаданными карточек (возрастной рейтинг, оценка, год, хронометраж) и моментальным переходом к просмотру.
- **Единый агрегатор контента:** интеграция с каталогом TMDB (популярное, тренды, цифровые новинки, сериалы в эфире, сезоны и серии).
- **Прямые российские источники:** параллельный поиск и прямое воспроизведение видеопотоков (HLS/MP4) и трейлеров из сетей **VK Video** и **Rutube** без прокси-серверов с фильтрацией экранок.
- **Воспроизведение:** встроенный оптимизированный аппаратный плеер (AndroidX Media3 / ExoPlayer) с управлением пультом ДУ, поддержкой HLS/MP4, точной изоляцией прогресса по каждой серии, автозатемнением при паузе (>30 сек) и аппаратным сглаживанием звука (+3 dB).
- **10-foot UI / NUM Design:** бесконечные полки в 1 ряд, адаптивное боковое меню, полка сезонов и серий с превью, блок «В главных ролях», фильмография актеров, аппаратные скругления 10dp, плавная бегущая строка названий, мягкие неослепляющие индикаторы и селекторы фокуса.
- **Настройки и управление данными:** встроенный экран настроек (без разрыва бокового меню), управление ключом TMDB, переключатель автовыравнивания звука (+3 dB), ручная синхронизация каналов Android TV, очистка истории (строгий лимит в 30 записей) и избранного.
- **Полная автономность:** без сторонних серверов, регистраций и авторизаций. Локальное хранение истории и избранного в Room SQLite.
- **Автообновление:** проверка новых версий на GitHub при холодном старте приложения и установка APK через системный PackageInstaller.
