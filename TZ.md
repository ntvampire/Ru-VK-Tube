# Техническое задание (ТЗ): RuVK Hub

## 1. Общие сведения и назначение
**RuVK Hub** (ранее *Ru-VK-Tube*) — автономный агрегатор и медиаплеер каталога фильмов и сериалов, спроектированный специально для устройств **Android TV** (телевизоры, медиаприставки, проекторы) с управлением исключительно с 5-позиционного пульта ДУ (D-pad: Вверх, Вниз, Влево, Вправо, Ок/Выбор, Назад).

### Ключевая концепция
- **Полная автономность:** Приложение работает по архитектуре *Serverless Client*. Нет сторонних прокси-серверов, авторизаций, учетных записей или баз данных на сервере разработчика.
- **Интеграция открытого каталога:** Метаданные, постеры, кадры, описания, рейтинги и актерский состав берутся напрямую из The Movie Database (TMDB).
- **Прямые отечественные источники:** Видеопотоки (HLS `.m3u8` и MP4) и русскоязычные трейлеры находятся и воспроизводятся напрямую из открытых платформ **VK Video** и **Rutube**.
- **10-foot UI / Leanback Design:** Интерфейс оптимизирован для комфортного просмотра с расстояния 3 метров (крупные контрастные карточки, анимации масштабирования при фокусе, плавные выдвижные полки).

## 2. Системные требования и стек технологий

| Компонент | Технология / Параметр | Назначение |
|---|---|---|
| **Язык разработки** | Kotlin 2.0.20 | Основной язык приложения |
| **Целевая платформа** | Android TV (Leanback) | Поддержка Android 5.0+ (API 21–34), основной фокус: Android TV 9.0–14.0 |
| **Сборка** | Gradle 8.8 / AGP 8.5.2 | Сборка и подпись APK |
| **Схемы подписи APK** | v1 (JAR) + v2 + v3 | Гарантия совместимости со всеми прошивками вендоров (Philips, Sony, TCL, Xiaomi) |
| **Сетевой стек** | OkHttp 4.12.0 + Retrofit 2.11.0 + Gson | Работа с REST API TMDB, парсинг страниц и API VK/Rutube |
| **DNS-резолвер** | Кастомный `TmdbDns` (Quad9 9.9.9.9 via UDP) | Обход блокировок и некорректных ответов локальных DNS-провайдеров для `api.themoviedb.org` |
| **Асинхронность** | Kotlin Coroutines + Flow | Фоновая загрузка каталогов, поиск потоков, неблокирующий UI |
| **Локальная БД** | Room SQLite 2.6.1 | Хранение истории просмотров, таймкодов прогресса и избранного |
| **Загрузка изображений** | Coil 2.6.0 | Кэширование и нарезка битмапов с радиусом скругления 10dp |
| **Встроенный плеер** | AndroidX Media3 / ExoPlayer 1.3.1 | Аппаратное воспроизведение HLS / MP4 потоков |
| **Внешние плееры** | Android Intent (`ACTION_VIEW`) | Запуск VLC, Vimu Media Player, Just Player по выбору пользователя |

## 3. Архитектура и структура модулей

```
com.ruvk.tube/
├── data/
│   ├── api/tmdb/        # Retrofit API, DTO модели и репозиторий TMDB (Credits, Details, Search, Feeds)
│   ├── db/              # Room Database, DAO и сущности (Favorites, History)
│   ├── local/           # SharedPreferences и AppPreferences (настройки плеера, API ключи)
│   ├── network/         # NetworkClient, User-Agent интерцепторы и TmdbDns резолвер
│   ├── scrapers/        # Парсеры видеопотоков Rutube и VK Video
│   └── update/          # UpdateManager: проверка обновлений (GitHub Pages / API), загрузка и установка
├── domain/
│   ├── models/          # Чистые доменные модели (MediaItem, VideoSource, CastMember, MediaType)
│   └── search/          # Координатор параллельного поиска источников в VK и Rutube
├── player/              # Встроенный ExoPlayer (InternalPlayerActivity), оверлей управления, запуск внешних плееров
└── ui/
    ├── details/         # Карточка фильма/сериала (DetailsActivity, NumCastAdapter, NumSourceAdapter)
    ├── main/            # Главный экран (MainActivity, NumPosterAdapter, NumSideMenuAdapter)
    └── settings/        # Экран настроек (SettingsActivity: выбор плеера, TMDB ключ, обновления)
```

## 4. Функциональные требования к экранам

### 4.1. Главный экран (`MainActivity`)
1. **Hero Spotlight (верхний информационный блок):**
   - Фоновый бэкдроп высокого разрешения с затемняющими градиентами.
   - Крупное название фильма/сериала, оригинальное название.
   - Мета-бейджи: возрастной рейтинг (`18+`, `16+` из российского или международного классификатора), рейтинг TMDB (`★ 8.2`), год премьеры, хронометраж в минутах.
   - Синопсис (краткое описание сюжета до 4 строк).
   - Индикатор недосмотренного прогресса (красная полоса в стиле YouTube).
2. **Бесконечная лента каталога (`HorizontalGridView`):**
   - Расположение: 1 ряд в нижней части экрана (высота 225dp).
   - Анимация: увеличение карточки до 1.08x при наведении пульта, белая рамка селектора.
   - Скругление: аппаратное скругление постера 10dp (`clipToOutline = true` + `RoundedCornersTransformation`).
   - Пагинация: автоматическая дозагрузка следующей страницы TMDB за 5 карточек до конца списка.
3. **Боковое быстрое меню (NUM-style):**
   - Ширина: 68dp в свернутом состоянии, 220dp при уходе курсора влево.
   - Шапка: двухцветный заголовок **RuVK** (`#0A82FF`) **Hub** (`#FF3C4B`), выровненный влево вровень с пунктами меню (20dp от края), шрифт 20sp bold. В свернутом виде плавно скрывается.
   - Разделы:
     - 🔍 *Поиск* (встроенный ввод или клавиатура Android TV).
     - 🔥 *В тренде* (тренды дня TMDB).
     - 💥 *Новинки* (фильмы, официально вышедшие в цифровой релиз, исключая кинотеатральные экранки).
     - 📺 *В эфире* (актуальные сериалы недели).
     - 🎬 *Фильмы* (популярное кино).
     - 🖥 *Сериалы* (популярные телешоу).
     - ❤️ *Избранное* (локальный список Room).
     - 🕒 *История* (локальная история с позициями).
     - ⚙️ *Настройки*.
   - **Пустые состояния:** центрированная аккуратная заглушка без остаточных артефактов и бейджей; фокус пульта удерживается в боковом меню.

### 4.2. Экран детальной карточки (`DetailsActivity`)
1. **Шапка фильма:** вертикальный постер 190x280dp (10dp скругление), заголовок, бейджи, синопсис.
2. **Панель действий (минималистичные иконки 46x44dp):**
   - Кнопка **Смотреть / Продолжить**: иконка ▶. Если фильм уже начинали смотреть, рядом отображается сохраненный таймкод в скобках, например: `▶ (42:15)`. При нажатии сразу возобновляется сохраненный поток либо открывается панель источников.
   - Кнопка **Источники**: иконка 🔍. Принудительное открытие полки источников.
   - Кнопка **Трейлер**: иконка 🎬. Поиск и запуск дублированного трейлера на Rutube / VK Video.
   - Кнопка **Избранное**: иконка ♡ / ♥. Добавление и удаление из Room DB.
3. **Полка «Источники»:**
   - Появляется при нажатии «Смотреть» или «Источники».
   - Фоновый параллельный парсинг Rutube и VK Video через `SearchCoordinator`.
   - Карточки источников: платформа (красный Rutube / синий VK Video), качество (1080p, 720p, 480p), признак озвучки/дубляжа, длительность видео.
   - Жесткая фильтрация экранок (TS, CAM, HDCAM, TeleSync).
4. **Полка «В главных ролях»:**
   - Горизонтальная полка первых 12 актеров (TMDB Credits).
   - Круглые фото актеров (`RoundedCornersTransformation`), имя и персонаж.
   - Анимация фокуса 1.06x с белой окантовкой.
   - **Динамическое позиционирование:** блок актеров расположен сразу под кнопками; при открытии источников плавно съезжает вниз под них.
5. **Полка «Фильмография актера»:**
   - Активируется по клику на карточку любого актера.
   - Подгрузка фильмов и сериалов из TMDB (`person/{id}/combined_credits`).
   - Сортировка **от новых к старым** по дате премьеры.
   - 1 ряд постеров (225dp). Клик по фильму открывает его карточку; Back возвращает фокус на актера.

### 4.3. Видеоплеер (`InternalPlayerActivity` / External)
- Встроенный аппаратный плеер на базе Media3 ExoPlayer.
- Поддержка HLS (`.m3u8` master playlists) и прямых MP4.
- Оверлей: пауза/воспроизведение, прыжки +/-10 секунд, длинная перемотка с удержанием, таймлайн с текущим и общим временем.
- Периодическое автосохранение позиции просмотра в Room DB (для возобновления с того же места).
- Поддержка внешних плееров (VLC, Vimu, Just Player) через системный диалог Android Intent.

### 4.4. Экран настроек (`SettingsActivity`)
- Переключение плеера по умолчанию (Встроенный ExoPlayer / Внешний плеер).
- Ввод персонального TMDB API ключа (с сохранением в SharedPreferences).
- Кнопка «Проверить обновления» с отображением текущей версии и истории изменений.

### 4.5. Подсистема автообновления (`UpdateManager`)
- Двухуровневый опрос:
  1. Основной: `https://ntvampire.github.io/Ru-VK-Tube/update.json`.
  2. Резервный: GitHub REST API `api.github.com/repos/ntvampire/Ru-VK-Tube/releases/latest`.
- Сравнение версий по семантическому номеру (`isVersionNewer`).
- Фоновая загрузка APK с прогресс-баром в системную директорию `Downloads`.
- Запуск системного PackageInstaller через `FileProvider` (`${applicationId}.fileprovider`).

## 5. Планы на следующий этап (Сериалы)
1. **Структура сезонов и серий:**
   - Запрос списка сезонов через TMDB `/tv/{id}`.
   - Запрос списка серий выбранного сезона через TMDB `/tv/{id}/season/{season_number}` (названия, номера, превью серий).
2. **Двухуровневый селектор на UI:**
   - Ряд переключателей сезонов: `[1 сезон] [2 сезон] ...`
   - Ряд карточек серий: `1 серия`, `2 серия` с превью и описанием.
3. **Интеллектуальный поисковый движок серий:**
   - Поддержка поиска точечных серий в VK и Rutube по регулярным выражениям: `"$title 1 сезон 2 серия"`, `"s01e02"`, `"сезон 1 серия 2"`.
   - Поддержка плейлистов/альбомов (если сериал загружен плейлистом на Rutube/VK).
4. **История сериала:**
   - Сохранение прогресса в Room DB по ключу `(tmdbId, seasonNumber, episodeNumber, positionMs)`.
   - Автоматический переход к следующей серии при завершении текущей.
